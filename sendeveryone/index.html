What it does

Pick contacts once, save them as a group, and send an SMS, iMessage or email to everyone in one tap. Messages go through Apple’s own Messages and Mail compose screens — you always review before sending.

Features

  • Quick select — tick phone numbers or emails straight from your contacts, with A–Z index and pinyin search for Chinese names
  • Groups — save recipients as reusable groups, or add them to an existing group (duplicates are skipped)
  • Default send type — each group sends as Message or Email; long-press Send to use the other one
  • Email To / Cc / Bcc — choose how each address is included
  • Limited contacts access — works even if you only share some contacts

Available for iPhone and iPad. The Apple Watch app has been retired as of version 3.0.

FAQ

Why do I need to tap Send in Messages?
iOS doesn’t allow apps to send texts silently. SendEveryone fills in the recipients; you write the message and send it yourself.

My groups from the old version are gone.
Version 3.0 is a complete rewrite with a new storage format, so groups from version 2.x could not be carried over. Please recreate them — it only takes a few taps.

Will recipients see each other?
A group SMS/iMessage shows all recipients to everyone. For email, put recipients in Bcc to keep addresses private.

常见问题

为什么还要在信息里点发送？
iOS 不允许 App 在后台直接发短信。SendEveryone 帮你填好收件人，内容由你编写并亲自发送。

旧版本的群组不见了？
3.0 是全新重写的版本，数据格式不同，2.x 的群组无法迁移，需要重新创建。

收件人能看到彼此吗？
群发短信/iMessage 时所有收件人互相可见。发邮件时可以把收件人设为密送（Bcc）来保护地址。

概要

連絡先を選んでグループとして保存し、SMS・iMessage・メールをワンタップで全員に送信できます。送信は Apple 標準のメッセージ／メール画面を使うため、送信前に必ず内容を確認できます。

機能

  • クイック選択 — 連絡先から電話番号やメールを直接選択。A–Z インデックスと検索に対応
  • グループ — 宛先をグループとして保存、既存グループへの追加も可能（重複は自動でスキップ）
  • デフォルトの送信方法 — グループごとにメッセージかメールを設定。送信ボタンの長押しでもう一方を使用
  • メールの To / Cc / Bcc — アドレスごとに設定可能
  • 連絡先の限定アクセス — 一部の連絡先のみ許可していても利用可能

iPhone と iPad に対応。バージョン 3.0 より Apple Watch アプリは提供を終了しました。

よくある質問

なぜメッセージ画面で送信をタップする必要があるのですか？
iOS ではアプリが自動でメッセージを送信することはできません。SendEveryone は宛先を入力し、本文の作成と送信はご自身で行います。

旧バージョンのグループが消えました。
3.0 は全面的に作り直したバージョンで保存形式が異なるため、2.x のグループは引き継げません。お手数ですが再作成してください。

受信者同士はお互いが見えますか？
グループ SMS／iMessage では全員が表示されます。メールの場合は Bcc を使うとアドレスを非公開にできます。
